========================================
    🧠 NeuroNest - Quick Start Guide
========================================

HOW TO START THE APPLICATION:
------------------------------
Double-click this file:
    🚀 START NEURONEST.bat

The launcher will:
1. Start backend server
2. Start frontend server  
3. Wait for both to be ready
4. Automatically open your browser
5. Load NeuroNest at http://localhost:5175

FIRST TIME SETUP:
-----------------
If this is your first time, run these commands:

1. Install backend dependencies:
   cd backend
   npm install

2. Install frontend dependencies:
   cd frontend
   npm install

3. Then double-click: 🚀 START NEURONEST.bat

TO STOP THE SERVERS:
--------------------
Close the terminal window that appears, or press Ctrl+C
