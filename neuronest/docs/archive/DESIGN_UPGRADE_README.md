## 🎨 Customization Guide

### Change Primary Color:
Edit in `tailwind.config.js`:
```javascript
colors: {
  gold: {
    400: '#YOUR_COLOR',
    // ...
  }
}
```

### Adjust Animation Speed:
Edit in `index.css`:
```css
.floating-orb {
  animation-duration: 20s; /* Change this */
}
```

### Modify Glass Effect:
```css
.glass-card {
  background: rgba(255,255,255,0.03); /* Transparency */
  backdrop-filter: blur(20px); /* Blur amount */
}
```
