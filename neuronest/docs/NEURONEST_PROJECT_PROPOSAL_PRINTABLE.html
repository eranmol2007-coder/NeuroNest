2. Project Overview

About NeuroNest

NeuroNest is a comprehensive cognitive care platform designed for dementia patients and their caregivers. It combines therapeutic games, mood tracking, personalized reminders, and AI-driven insights to improve quality of life and enable early intervention.

Current Capabilities

  • Cognitive Games: Memory Match, Pattern Recognition, Daily Routine Recall
  • Adaptive Difficulty: Rule-based system adjusting game complexity
  • Voice Assistant: Browser-based speech recognition for hands-free control
  • Mood Tracking: Daily emotional check-ins with visual history
  • Reminiscence Therapy: 6 themed interactive stories across 4 chapters each
  • Reminders: Medication, appointments, meals with audio alerts
  • Caregiver Dashboard: Patient monitoring and alert system
  • Multi-language Support: 9 languages including English, Hindi, Bengali, Assamese, and more

7. Web to App Conversion

Desktop App (Electron)

Electron wraps your React web app into a native desktop application that works on Windows, Mac, and Linux.

Advantages

  • Reuse 100% of web code
  • Native file system access
  • System tray integration
  • Auto-updates
  • Offline by default

Quick Setup

npm install --save-dev electron electron-builder
npm run electron:build  # Creates installers

Mobile App (Capacitor)

Capacitor converts your React web app into native iOS and Android apps with access to native device features.

Advantages

  • Reuse 95%+ of web code
  • Native camera access (for emotion detection)
  • Local push notifications (for reminders)
  • Offline storage
  • App store distribution

Quick Setup

npm install @capacitor/core @capacitor/cli
npx cap add android
npx cap add ios
npx cap sync  # Build and sync
